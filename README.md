# Лабораторная работа №4

Тема: Анализ учебного набора данных с помощью SQL.

Предметная область: образовательная платформа (учебные группы, студенты, преподаватели, курсы, записи на курсы и итоговые оценки).

Вариант: 8.

Вопрос варианта: как соотносятся продолжительность курса (hours) и средняя оценка? Сопоставьте курсы разной продолжительности.

Цель работы: научиться анализировать данные из нескольких связанных таблиц с помощью SQL, применять фильтрацию, сортировку, агрегирование, группировку и объединение таблиц, проверять целостность данных и формулировать аналитические выводы.

## Описание предметной области

Рассматривается образовательная платформа, которая хранит информацию об учебных группах, студентах, преподавателях, курсах, записях студентов на курсы и итоговых оценках.

Учебная база данных SQLite содержит шесть связанных таблиц:

| Таблица | Назначение | Количество записей |
|---|---|---:|
| groups | Учебные группы | 12 |
| students | Студенты | 240 |
| teachers | Преподаватели | 15 |
| courses | Курсы | 30 |
| enrollments | Записи студентов на курсы | 1000 |
| results | Итоговые оценки завершённых записей | 850 |
| Итого | | 2 147 |

Таблицы связаны между собой с помощью первичных и внешних ключей. Это позволяет анализировать записи на курсы в разрезе студентов и групп, курсов и преподавателей, а также исследовать итоговые оценки.

Для выполнения SQL-запросов используется онлайн-среда SandboxSQL.

## Выполненная работа

В ходе лабораторной работы:

1. Загружена база данных SQLite, проверено наличие шести таблиц и количество записей в каждой из них.
2. Изучены структура таблиц, их поля, первичные и внешние ключи. Сформулированы аналитические вопросы.
3. Выполнена фильтрация и сортировка данных с помощью WHERE, ORDER BY и LIMIT.
4. Рассчитаны агрегированные показатели с использованием COUNT, SUM, AVG, MIN, MAX. Выполнены группировка с GROUP BY и фильтрация групп с HAVING.
5. Исследованы связи между таблицами с помощью INNER JOIN и LEFT JOIN.
6. Выполнены проверки корректности данных и ссылочной целостности.
7. Проведено самостоятельное аналитическое исследование по варианту 8: сопоставлены курсы разной продолжительности по средней оценке, сформулированы выводы на основе результатов SQL-запросов.

## Результат

Подготовлен аналитический отчёт, содержащий описание структуры базы данных, аналитические вопросы, SQL-запросы, таблицы результатов, скриншоты их выполнения в SandboxSQL и выводы по каждому этапу.

По результатам анализа выявлено, что чёткой зависимости между продолжительностью курса и средней оценкой нет: средние оценки по группам длительности различаются на несколько баллов (от 75.07 до 79.19), а различия между отдельными курсами внутри одной группы больше.
